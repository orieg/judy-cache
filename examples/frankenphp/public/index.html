Under The Hood: Why Judy Uses ~84% Less Memory

1. 256-ary Compressed Bitmap Leaves

ext-judy groups keys into adaptive 256-ary digital tree leaves (LEAF1..LEAF7, LEAF_B1) with bit-packed immediate values. It computes offsets dynamically using single-cycle CPU instructions (POPCNT, BSWAP) rather than storing pointer arrays.

2. Zend Hash Table Overhead

A standard PHP array allocates a 36-byte Bucket struct per key, uint32 hash indices, collision chains, and powers-of-2 capacity allocations. Storing 10M keys in standard arrays requires 4.68 GB RAM vs 763 MB in Judy.
