Under The Hood: Why Judy Uses 80%+ Less Memory

ext-judy (256-ary Radix Trie)

Stores keys in hierarchical uncompressed/compressed bitmap leaf structures with hardware POPCNT and word-level BSWAP instructions. No per-element object headers or hash collision chains.

Zend Array (Hash Table)

Standard PHP arrays allocate a 36-byte Bucket struct per key, uint32 hash indices, and power-of-2 allocation tables, requiring 35–80+ bytes per integer key.
