Under The Hood: Why Judy Radix Tries Save ~84% Memory

C Hardware Bitmap Leaves vs. Zend 36-Byte Bucket Tables
1. 256-ary Compressed Bitmap Leaves (ext-judy 2.6.0)

Keys are grouped into adaptive 256-ary radix tree leaves (LEAF1..LEAF7, LEAF_B1) with bit-packed immediate values. Key offsets are calculated dynamically using single-cycle CPU instructions (POPCNT, BSWAP) with zero pointer arrays and zero per-entry structs.

2. Zend Hash Table Overhead (Standard PHP Array)

Each entry allocates a 36-byte Bucket struct, uint32 hash indices, collision chains, and powers-of-2 capacity doublings. At 10M keys, PHP arrays take 4.68 GB RAM vs 763 MB in Judy (~84% reduction).
